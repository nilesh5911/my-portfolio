Stock Price Forecasting

Developed LSTM and CNN-LSTM models for time-series stock price forecasting, incorporating feature engineering and visual performance metrics.

Project Overview

This project leverages Long Short-Term Memory (LSTM) neural networks to forecast stock prices based on historical data. The model analyzes time series data to predict future trends, achieving an 18% improvement in RMSE over baseline models. It is deployed via a Flask API for real-time predictions, providing actionable insights for traders and investors.

Technologies Used

LSTM Flask Keras Python Pandas

Key Features

  • Advanced LSTM and CNN-LSTM models for accurate forecasting.
  • Real-time prediction API with Flask backend.
  • Interactive visualizations of predictions vs actual prices.
  • Feature engineering for improved model performance.

Impact

The model demonstrates strong predictive capabilities, with RMSE reduced by 18% compared to traditional methods. It provides valuable insights for financial decision-making and can be integrated into trading platforms.
